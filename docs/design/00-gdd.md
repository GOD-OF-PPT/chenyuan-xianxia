## 1. 立项背景与核心愿景

### 1.1 为什么重新立项

前序 Web 动作原型（`chenyaun-v2`，《尘缘问道 · 剑阵万象》）验证了世界观雏形与部分工程方法，但也暴露出无法靠局部修补解决的根本问题：

1. **缺乏前置总体设计**：系统随版本堆叠至十余条养成线与 21 个键位，数值被迫层层打补丁封顶，界面同屏充斥十余个入口与数百处无仲裁飘字。
2. **表现形式与资源错配**：无锁定狂点左键的街机割草高度依赖逐帧打击动画；在单张静态贴图缩放变形、零散无规范生图的条件下，产生了强烈的“廉价塑料感”。
3. **仙侠韵味与玩法脱节**：古典仙侠最令人着迷的“修真丛林筹谋、门派奇门阵法、五行生克连携、本命灵宠养成、红颜宿命情劫”，在单人无锁定乱砍框架下沦为冰冷的百分比按钮。

因此，本项目正式独立立项，确立**大型单机古典仙侠角色扮演游戏（RPG）**方向：**融合《魔兽世界》自由走位锁定技能循环与《梦幻西游》阵法克制灵宠博弈，承载《凡人修仙传》×《诛仙》的冷峻修真与凄美情劫，先将全部子系统精心设计成册，再遵照文档在 Godot 4 中实施。**

### 1.2 一句话愿景（High Concept）

> “天地不仁，以万物为刍狗；仙路既断，我自执剑叩天！”——在天门崩裂百年、弱肉强食的九州修真界，身具“漏灵废体”的寒门少年顾长青怀揣神秘古器【断玉剑匣】步步为营，在尔虞我诈的宗门倾轧、刻骨铭心的红颜情劫与天下苍生的生死叩问间，率同道结奇门大阵、驭山海灵宠，杀出一条百折不灭的证道长生路。

## 2. 产品定位与目标受众

| 维度 | 规格定义 |
|---|---|
| **核心品类** | 单机古典仙侠 RPG · 区域制半开放世界 · **大地图无缝实时战术小队战斗（RTwP：魔兽式操控循环 × 梦幻式常驻阵法与换宠）** |
| **视觉形态** | 2D 斜俯视（经典《梦幻西游》/古典国风斜向视角）：分层手绘山水仙门建筑 + 8 方向精炼帧动画角色 + 高精度半身立绘演出 |
| **目标平台** | **PC（Steam）买断制单机**（无内购、无抽卡、无联网强制）；Web 导出仅用于早期试玩切片分发 |
| **操控基准** | **纯正 PC 键鼠原生设计（明确不做手柄适配）**——充分发挥键鼠在 WASD 走位、鼠标点选/框选、快捷栏 `1~8`/`QERF` 施法、Tab 切怪与空格战术暂停微操上的绝对优势 |
| **技术引擎** | **Godot 4**（GDScript + Resource 数据驱动架构） |
| **基准规格** | 1920×1080 基准分辨率；简体中文母语创作，底层全文本 ID 化抽取（CSV/PO），预留繁中/英文扩展能力 |
| **目标体量** | 全作 **40–60 小时**（6 大九州区域 / 9 章三幕剧）；首个交付物为 **1–2 小时第一章精品垂直切片** |

### 2.1 目标玩家画像与难度哲学

- **核心受众**：热爱《梦幻西游》《魔兽世界》深度技能配装博弈，同时痴迷《凡人修仙传》《诛仙》及经典国产单机仙侠（仙剑/古剑）世界观与情感张力的 PC 玩家。
- **难度取向——“重筹备、讲战术、不枯燥刷怪”**：
  - 呼应《凡人修仙传》“未战先算”的修真真实感：战前阵法选择、五行灵丹筹备、法宝词条与首发灵宠搭配占一半胜算；战中仇恨牵制、读条打断、走位躲圈与五行相生连携占另一半胜算。
  - **三档难度随时可调**（不影响剧情分支与真结局资格）：**问心（剧情） / 修行（标准，默认验收基准） / 渡劫（困难）**。

## 3. 四大体验支柱与标杆参考边界

| 体验支柱 | 玩家应当感受到的具体体验 | 铁律级制作取舍 |
|---|---|---|
| **1. 斗法有谋** | 告别狂点左键！锁定目标自动普攻，精力聚焦于魔兽式 GCD 技能循环、读条打断、铁三角仇恨拉扯、五行破罡连携，以及梦幻式常驻阵法克制与战中换宠 | **清晰可读的技能机制与职责分工优先于满屏乱飞的廉价粒子** |
| **2. 人在世界里** | 修真界有真实的残酷丛林法则（筑基丹争夺、杀人夺宝、仙凡冷暖），亦有至死不渝的微末真情；同伴各有师承私心与底线，世界随大事件真实演变 | **人物立体动机与修真生态真实感优先于喊口号式的扁平脸谱** |
| **3. 修行有选择** | 破境、阵图、法宝、丹药、炼器与灵宠带来**截然不同的小队战术流派**（如地载阵双奶反伤流、天覆阵木火速爆流、血宠忠心挡刀流） | **横向流派构建优先于纵向白值膨胀**；严格执行全局收益预算 |
| **4. 旅程有节奏** | 坊市淘宝炼丹的静谧筹谋、秘境探宝的步步惊心、红颜夜话的温存、锁灵仙台惊变的撕心裂肺交替推进 | **心流呼吸感优先于密集弹窗轰炸** |

### 3.1 四大灵感源头的精准汲取边界

- **《魔兽世界》（WoW）**：汲取**大地图无缝开战、锁定目标自动平砍、1.5s 公共冷却（GCD）与技能 CD 循环、施法吟唱条与关键打断、T/奶/DPS 仇恨铁三角职责、Boss 阶段转换与地面预警走位**；不照搬网游日常打卡与冗长跑尸。
- **《梦幻西游》**：汲取**2D 斜俯视精致国风审美、常驻全队光环与阵阵相克的奇门阵法（天覆/地载/风扬/虎翼/龙飞等）、极具深度的灵宠宝宝养成与战中读条换宠（攻宠点杀、配速血宠护主）**；不照搬点卡时代的暗雷抓鬼刷经验与几率碎装备坑钱。
- **《凡人修仙传》**：汲取**冷峻写实的修真资源生态、伪灵根/废脉主角冷静隐忍审时度势的心智、核心神秘机缘【断玉剑匣】财不露白的危机感、筑基结丹九死一生的筹备仪式感**；不写成毫无感情的孤狼流水账。
- **《诛仙》**：汲取**“天地不仁”的苍凉宿命叩问、名门正派青云宗道貌岸然下的伪善残酷、以及双红颜（温润清韧的沈清禾 vs 痴绝挡剑冰封沉睡的妖女泠月）催人泪下的生死情劫**。

## 4. 核心叙事命题、人设升级与三大终局

### 4.1 凡人底色 × 诛仙情劫：顾长青的逆命问道之路

- **世界残酷真相**：百年前九霄天门实为抽汲九州地脉的【归天虹吸大阵】，觉悟先贤自斩天门救世，坠落阵心化为五枚【天门道影】；各大仙门高层一边掩盖真相维持高高在上的统治，一边因寿元将枯暗中勾结或纵容宿敌萧断云的【叩天会】，妄图献祭五境残脉强铸天门。
- **主角顾长青（冷静隐忍 × 执剑逆命 × 至情重义）**：
  - 童年故村遭妖祸，青云高修因他测无灵根（实为太初混沌漏灵废体）视若草芥弃之不救，至亲惨死。他怀揣绝密古器**【断玉剑匣】**（兼具聚灵破境与收纳器灵洞天之能，一旦暴露必引大能追杀）踏入修真丛林。
  - 他平日行事如《凡人》韩立般谨慎周密、懂藏拙、重后手；但骨子里深埋不甘天命的傲骨，且对微末时救命相伴的医修**沈清禾**、秘境绝地中生死相惜的叩天会圣女**泠月**倾注真情。
  - **中盘惊世情劫（第五章·锁灵仙台之变）**：青云太上长老贪图剑匣与残枢，催动护山诛仙杀阵围杀顾长青；圣女**泠月**逆反义父之命，燃尽本源替顾长青挡下灭魂神雷，三魂俱寂、肉身冰封于【断玉剑匣】之中。自此，顾长青后半程的求仙执念不仅为证己道，更为**“踏上九霄天门，夺回她一线生魂”**！

### 4.2 三大终局（全程抉择、势力声望与救赎条件共同导向）

1. **结局一 ·【孤峰证道 · 踏碎天门】（执念极境）**：斩灭宿敌萧断云，以五境残枢强开天门登临真仙，虽以仙界伟力保住残魂，却令九州灵脉彻底干涸、人间故友永隔仙凡。
2. **结局二 ·【留道人间 · 散仙镇世】（反哺苍生）**：亲手斩断旧天门仙桥，散尽一身化神道果重续九州地脉与清禾、苏醒的泠月共守凡尘百年岁月，终身不再言仙。
3. **结局三 ·【尘缘辟道 · 万古新天】（真结局）**：参透全部先贤残碑、统合五境同盟并集齐还魂奇物后开启——以混沌凡脉容纳四象红尘，在九霄之上斩碎虹吸旧法、重立不伤苍生的人间新道，唤醒冰封红颜，与众同道共证真逍遥。

## 5. 世界结构与小队编制

- **区域制半开放世界（6 大区域 · 9 章三幕剧）**：青岚境（木）→ 青云境（金）→ 照影境（水）→ 赤渊境（火，**结成金丹解锁大地图【御剑飞行】**）→ 青云锁灵惊变 → 剑墟境（土，元婴【神识破妄】）→ 九霄云境（混元终局）。大地图无缝衔接探索与战斗，高危区设境界威压软门槛。
- **战斗同屏黄金编制（4 人小队 + 1 领队出战灵宠 = 我方最多 5 实体）**：
  - 全作可招募 **8 名角色**（顾长青常驻 + 沈清禾、裴照、陆玄松、砚尘、红袖、公输岳、泠月）；
  - 出战 **4 人**绑定奇门阵法 1~4 号阵位，外加顾长青灵兽袋常驻出战 **1 只实体灵宠**（备战槽可带 **3 只灵宠支持战中读条换宠**）。

## 7. 质量铁律与制作管线

1. **美术圣经与 1080p 四张目标样片先行（闸门 3）**：对标《梦幻西游》温润浓郁的 2D 斜俯视国风建筑山水与清晰角色轮廓，AI 初稿必经人工精修统一透视、勾线与色板，全量登记 `art-manifest`。
2. **纯正 PC 键鼠 HUD 与唯一通知中枢**：底部经典魔兽式快捷栏 + 顶部/侧边清晰仇恨与读条框体 + 干净战斗飘字分级；过场对话期间静默一切战斗 UI。
3. **收益预算封顶在前**：先在 `11` 号文档锁定每章生命、攻击、治疗、冷却急速的总盘子（境界约 45% / 兵甲法宝约 35% / 阵法丹药灵宠约 20%）。

## 8. 第一章精品垂直切片（1–2 小时）验收门槛

- **范围**：核心 8 项闭环——青岚境听雨镇坊市 + 破庙山道 + 苍木禁制古窟；无缝大地图 RTwP 战斗（顾长青 + 沈清禾 + 裴照 3 人成阵，掌握天覆/地载 2 套基础阵法、五行破罡与相生连携、空格战术暂停）；断玉剑匣初醒与 3 张关键丹方；章末雾隐狼王首领战与“夺灵髓秘修 vs 散灵髓救镇”的首次《凡人》×《诛仙》式道心抉择。
- **5–8 名目标新玩家零教学试玩门槛**：≥ 80% 在 75–135 分钟顺畅通关，熟练使用 WASD 走位躲危招、快捷栏打断与空格暂停调配清禾治疗/裴照破罡，并对战斗爽感、修真氛围与画面质感给出正向评价后，方进入后续章节扩量。
