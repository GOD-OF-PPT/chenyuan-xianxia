## 1. 设计目标

1. **服务支柱一（斗法有谋）与支柱三（修行有选择）**：将**《魔兽世界》的实时锁定技能循环（WASD 自由走位、自动普攻、1.5s GCD、吟唱打断、T/奶/DPS 仇恨铁三角）**与**《梦幻西游》的古典仙侠博弈精髓（全队常驻奇门光环阵法、阵阵相克、灵宠宝宝技能搭配与战中读条换宠）**无缝熔于一炉。
2. **从机制底层消灭街机割草“塑料感”**：玩家不再对着空气狂点鼠标左键，而是像指挥一支配合默契的修真小队——远程引怪开战、镇岳位稳拉背向仇恨、走位规避地面危招、抓住首领读条窗口打出克制破罡与五行相生连携，随时可按**空格键【战术凝时】**从容微操全场。

## 2. 玩家体验（三尺度战斗感受）

- **30 秒（单波明雷遭遇 / 拉怪开战）**：在大地图看到前方巡逻的瘴毒妖狼，Tab 锁定头狼、预读一发飞剑引怪；2 号玄武位队友自动迎上接怪拉稳杀意（仇恨），主控顾长青绕背自动平砍穿插 `1/2/3` 剑诀，配合沈清禾挂上的【苍木印】引爆火系连携，干净利落清场，无需切屏黑幕等待。
- **5 分钟（秘境精英 / 区域首领战）**：首领开启【厚土护罡】并读条 2.5 秒全屏危招；玩家一拍**空格键冻结时间**，框选后排沈清禾拉出红圈、切 `F2` 令裴照施展木/金破罡打断技、同时用 `Ctrl+2` 让血宠灵龟开启【忠心护主】分摊主坦重伤；松开空格，整套战术行云流水兑现，成就感拉满。
- **1 小时（秘境推进与筹备循环）**：根据秘境怪物主五行与敌阵类型，在休整点切换克制阵法（如从天覆阵改换地载阵）、调整队友战术 AI 阈值、分配灵兽袋 3 只备战灵宠的出场顺序，感受《凡人修仙传》“算定而后动”的修真斗法魅力。

## 3. 核心战斗规则（可直接编码规格）

### 3.1 大地图无缝开战与脱战规则（Seamless Engagement）

1. **无缝切入战斗**：不设传统回合制切屏加载。当小队进入野外/秘境明雷敌群的警戒半径，或我方主动对目标施放先手技能（Pulling）时，即刻原地进入战斗状态（底部快捷栏与小队仇恨框高亮，奇门阵法常驻光环激活）。
2. **先手破袭优势**：脱战状态下用远程法术/飞剑主动命中未察觉敌人，全队获得 4 秒【先机】（急速 +15%，首击破罡效率 +50%）；反之若背身遭伏击妖物偷袭，则受 2 秒短暂迟滞。
3. **牵引边界（Leash）与脱战恢复**：每组敌群拥有明确的领地追击半径；拉出边界或全灭当前仇恨链敌人后自动脱战。脱战 3 秒后气血与真元按境界速率自然回升（重伤倒地队友自动以 20% 气血复苏，但会叠加一层需丹药或营地休息清除的【经脉暗伤】以防无限拖尸）。

### 3.2 锁定自动普攻、全局调息（GCD）与吟唱打断体系

彻底废除“按一次左键挥一剑”的无脑连点模式，严格实行《魔兽世界》经典时间节奏：

1. **自动普攻（Auto-Attack / 凡锋平砍）**：
   - 选中敌方目标并开启攻击（右键点击敌人或按下任一攻击技能）后，只要处于武器射程内（近战 2.2 米，飞剑/法器 9 米），角色按武器固有攻速间隔（如重剑 2.4s、长剑 1.8s、双刃 1.4s）**全自动挥砍**，走位移动不重置普攻计时器（支持走A拉扯）。
2. **全局调息（GCD = 1.5 秒基准）**：
   - 绝大多数主动武技、五行仙术、阵旗指令共享 **1.5 秒全局调息**（受急速属性适度缩减，下限 1.0 秒），让操作具备清晰稳重的韵律感。
   - **不占 GCD 的关键救急项（Off-GCD）**：专属打断技（如【剑指封喉】）、保命减伤大招、瞬发急救灵丹（独立丹药冷却 30s），确保危急时刻随按随出绝不卡手。
3. **吟唱读条（Cast Time）与破功打断**：
   - 强力范围仙术、大额治疗术、战中换宠（1.5s）以及敌方精英/首领的高危杀招均需站定**读条吟唱（1.2s ~ 3.0s）**。
   - 读条条框明确区分颜色：**琥珀金条 = 可被打断技中断**（成功打断后目标陷入 3 秒【破功封脉】，同系法术锁死且承受额外破罡）；**暗红锁链条 = 不可常规打断**（必须靠走位出圈、开减伤硬吃，或彻底击碎其【五行护罡】强行破招）。

### 3.3 杀意（仇恨铁三角）与职责分工

每个进入战斗的敌人维护一张实时动态**杀意表（Threat Table）**：

- **杀意计算公式**：`单次行动杀意 = (实际伤害量 × 阵位杀意系数 × 姿态系数) + (有效治疗量 × 0.5 × 均摊存活敌人数) + 技能固定附加杀意`。
- **OT（仇恨转移）防抖阈值**：遵循魔兽经典防乱跑规则——近战范围内其他角色杀意须超过当前目标 **110%**、远程角色须超过 **130%**，怪物才会切换攻击目标，杜绝怪物在战场上鬼畜来回折返。
- **嘲讽（Taunt）机制**：玄武位主坦（公输岳、陆玄松，或忠心血宠）拥有【镇岳喝令】，瞬发强制复制当前最高杀意并锁定目标攻击自身 3 秒。

### 3.4 正五行“破罡 + 相生连携”双核机制

#### A. 五行相克：削减【护体灵罡】与【破绽】爆发
- **克制闭环**：**金克木 → 木克土 → 土克水 → 水克火 → 火克金**。
- 精英与首领生命条下方拥有一条带明确五行标识的**【护体灵罡】**（如雾隐狼王为【木灵罡】）。灵罡存在期间，首领免疫硬控并享有 25% 常驻减伤。
- **克制收益**：
  - 使用**相克五行**技能命中：造成 **1.25 倍属性伤害**，并对【护体灵罡】造成 **250% 巨额削罡**！
  - 使用被克五行命中：伤害为 **0.8 倍**，削罡效率仅 **50%**。
- **【破绽】窗口**：灵罡归零瞬间，目标当前一切读条强制中断，陷入 **6 秒【气机破绽】**（瘫痪眩晕 2 秒 + 全程承伤提高 35%），是全队开本命法宝与双人合击倾泻火力的黄金爆发期；6 秒后首领重聚灵罡（部分多阶段首领会切换灵罡五行，逼迫小队轮换输出重心或换宠）。

#### B. 五行相生：队友 GCD 印记接力（Elemental Synergy）
- **相生闭环**：**木生火 → 火生土 → 土生金 → 金生水 → 水生木**。
- 当一名角色或灵宠施放核心五行技能命中目标时，为目标附着持续 **6 秒的【五行母印】**（同一目标同时间仅保留最新一枚母印，状态栏大图标醒目提示）。
- 若在 6 秒内，另一技能以**相生子属性**命中该目标，立即吞噬母印引爆**【五行相生连携】**，并为全队额外积攒 **+15 点【同调气机】**（满 100 点可释放双人羁绊合击）：

| 母印 → 子技 | 连携名号 | 战术爆发效果 | 典型小队配合示例 |
|---|---|---|---|
| **木 → 火** | **【木生火 · 燎原】** | 立即结算一次高额范围火爆伤害，并传染周围 4 米敌人灼烧 | 沈清禾【青藤缠】挂木印 → 裴照/红袖烈火剑刀引爆清群怪 |
| **火 → 土** | **【火生土 · 熔岩】** | 在目标脚下生成熔岩裂地减速 40%，并为我方当前主坦附加一层岩石护盾 | 红袖火刀挂火印 → 公输岳重击接力，兼顾控场与稳固前排 |
| **土 → 金** | **【土生金 · 淬锋】** | 本次金系攻击无视目标 40% 护甲且必定暴击，额外削减双倍护罡 | 陆玄松土雷符挂土印 → 裴照【惊鸿一剑】打出毁天灭地破罡单体暴击 |
| **金 → 水** | **【金生水 · 凝渊】** | 触发【玄冥凝冰】寒气溅射，降低目标 25% 攻速与读条速度 5 秒，回复施法者 8% 真元 | 裴照金剑挂金印 → 泠月/砚尘水冰咒术接力，废掉狂暴首领攻势 |
| **水 → 木** | **【水生木 · 回春】** | 在目标周围绽放生机灵雾，立即为气血最低的 2 名我方单位恢复生命并驱散 1 层毒瘴 | 砚尘/水宠挂水印 → 沈清禾木系术法接力，DPS 与急救抬血一举两得 |

### 3.5 梦幻西游式“奇门常驻光环阵法”（不画地为牢）

吸取《梦幻西游》阵法精髓并完美适配实时走位：**阵法一经开启即化作全队气脉常驻光环，队员无论在场上跑开多远躲技能，1~4 号阵位属性加成 100% 持续生效，绝不束缚走位自由！**

1. **五大经典奇门阵法与阵位分配**（战前自由编排谁站 1~4 号位；战中消耗 1 枚阵旗或领队技能可切换阵法，冷却 45 秒）：

| 阵法名称 | 1号位（领队阵眼） | 2号位（前锋位） | 3号位（灵枢位） | 4号位（奇袭位） | 阵法整体定位 |
|---|---|---|---|---|---|
| **【普通散阵】** | 全属性无增减 | 全属性无增减 | 全属性无增减 | 全属性无增减 | 未习得阵书时的初始状态 |
| **【天覆阵】** | 法伤/剑伤 +18%，移速 -8% | 伤害 +15%，移速 -8% | 伤害 +15%，移速 -8% | 伤害 +15%，移速 -8% | 日常速推清怪、RUSH 爆发阵 |
| **【地载阵】** | 减伤 +15% | **减伤 +25%，杀意倍率 +80%** | 减伤 +10%，治疗量 +12% | 伤害 +8%，减伤 +10% | 开荒攻坚、越级抗高压首领铁桶阵 |

2. **阵法相克博弈**（敌方宗门修士小队与高阶妖阵首领同样会结阵！）：
   - **大克（伤害 +10%、承伤 -10%）**与**小克（伤害 +5%、承伤 -5%）**闭环：例如天覆克地载、地载克风扬、风扬克虎翼、虎翼克龙飞、龙飞克天覆。开战识破敌方阵名后临机变阵反克，尽显修真斗法策略感。

### 3.6 梦幻式“灵宠宝宝”与战中读条换宠（E3 战斗规则）

1. **同场编制上限**：我方最多 **4 名角色 + 1 只领队当前出战灵宠 = 5 个战场实体**，兼顾丰富度与画面清爽。
2. **灵兽袋 3 备战槽与战中换宠**：
   - 顾长青灵兽袋可配置 **3 只备战灵宠**（如 1 号【烈焰火狐·法系群秒宠】、2 号【玄水灵龟·高血忠心护主宠】、3 号【金翼雷鹰·高速打断攻宠】）。
   - 战中若当前灵宠气血归零退场（俗称“宝宝飞了”，本场不可再召该只），或战局突变需要换宠，领队可按宠物栏召出下一只备战灵宠（**需站定读条 1.5 秒并消耗 15% 真元，每场战斗最多换宠 2 次**），原汁原味复刻《梦幻西游》换宠翻盘的博弈快感！
3. **魔兽式迷你宠物控制条**：位于主快捷栏左上方，支持姿态切换（协助攻击领队目标 / 被动跟随 / 坚守原地）及 **2 个手控绝技键（`Ctrl+1`、`Ctrl+2`）**，如【神佑复生】【忠心护主（替残血主人分担 50% 致命伤）】【破咒驱散】。

### 3.7 【战术凝时（空格暂停）】与队友职责 AI

1. **随时空格凝时**：按下 `Space` 键，战场画面瞬间泛起淡墨水纹并**100% 冻结时间流逝**（可随时再按 `Space` 恢复实时流动）。
2. **凝时期间可执行的全部微操**：
   - 鼠标单选或左键拖拽框选任意队友/灵宠，右键地面下达**精准分散走位路径**（轻松化解需要 4 人分开躲避的机制，不靠电竞手速）；
   - 按 `F1~F4` 切换任意队员视角，点击其快捷栏为其**预排下一个 GCD 技能与指定目标**（如指定沈清禾对裴照预读解毒术、指定砚尘打断左翼祭司读条）。
3. **平时省心的可配置战术 AI**：无需每场小怪都频繁暂停！每名队友内置 3 套一键职责模板（如沈清禾【济世优先：队友血<65%自动读回春，有瘴毒秒驱散】、公输岳【死守阵前：自动拉住未受控敌人仇恨】），保证日常推图丝滑省力。

## 4. 数值与预算锚点（对接 `11` 号文档）

- **标准遭遇战时长基准**：同境界普通明雷怪群 **12–22 秒**；秘境守关精英 **45–75 秒**；章节主首领战 **120–210 秒（分 2–3 阶段）**。
- **单次受击防秒杀底线**：在【修行（标准）】难度同境界下，除明确预告超过 2.5 秒且玩家未走位未打断的灭团红圈危招外，首领常规重击对玄武位主坦单次伤害不超过其最大气血的 **35%**，对后排脆皮不超过 **60%**，给足治疗刷血与吃丹急救的反应窗口。
- **战斗内临时增幅封顶**：阵法光环 + 阵眼相克 + 丹药增益在战斗内的乘区总增幅严格纳入 `11` 号文档的 **20% 战术浮动预算池**，绝不允许叠出秒杀首领的崩坏一刀。

严格对齐 `21-ui-ux-spec.md` 唯一输入表（**无手柄冗余按键，纯正魔兽×RTS 键鼠直觉**）：

| 按键 | 战斗/探索功能 | 设计防呆说明 |
|---|---|---|
| **`W / A / S / D`** | 当前主控角色 8 方向自由走位 | 移动立即中断自身当前未完成的读条吟唱（走位躲圈零延迟） |
| **鼠标左键** | 点选敌友目标 / 拖拽框选多名我方队员（凝时微操） | **左键绝不绑定挥剑普攻**，根除狂点鼠标恶习 |
| **鼠标右键** | 对敌开启自动攻击 / 选中队友或框选时点击地面指定走位点 | 符合魔兽与 RTS 双重直觉 |
| **`Tab`** | 智能循环切换视野内敌方目标（优先选中正在读条的敌人！） | 方便第一时间抢断施法怪 |
| **`Space`（空格）** | **【战术凝时】开启 / 解除全场战术暂停** | 对白弹窗期间空格键严格屏蔽推进功能，绝不串键 |
| **`1 / 2 / 3 / 4`** | 当前主控角色 4 个核心武技 / 五行仙术（受 1.5s GCD 约束） | 图标高亮闪烁提示可触发【五行相生连携】 |
| **`Q` / `E`** | **`Q`：专属打断 / 身法位移技（不占 GCD）**；**`E`：职责招牌技（嘲讽 / 群抬 / 爆发）** | 黄金键位留给最高频反应动作 |
| **`R` / `G`** | **`R`：祭出本命法宝主动绝技**；**`G`：释放双人羁绊合击（满 100 气机亮起）** | 高分量大招独立键位 |
| **`5` / `6`** | 快捷丹药槽 1 / 槽 2（瞬发回春散、回元丹等） | 共享 30 秒丹毒调息，防止无限嗑药无脑过关 |
| **`Z` / `Ctrl+1,2`** | **`Z`：打开奇门变阵/换宠快捷小抽屉**；**`Ctrl+1/2`：灵宠主动绝技** | 致敬魔兽宠物条与梦幻换阵换宠 |
| **`F1 / F2 / F3 / F4`** | 秒切 1~4 号阵位队员为当前直接主控角色（双击居中镜头） | 默认 `F1` 为领队顾长青 |
