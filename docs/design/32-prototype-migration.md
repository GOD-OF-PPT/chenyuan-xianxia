## 1. 隔离总原则

原型仓库 `GOD-OF-PPT/chenyaun-v2`（《尘缘问道 · 剑阵万象》Web 动作版）已于 PR #39 合并后正式冻结归档。为确保新作《尘缘问道》纯粹、高质、零版权隐患、零历史代码包袱，确立以下三条铁律：

1. **代码 0 拷贝**：原型的 35k 行 JavaScript 单页运行时代码一律不迁入本仓库，所有规则按 `10`、`11`、`30` 号文档在 Godot 4 GDScript 中干净重写。
2. **未确权旧图 0 入库**：原型 `art-manifest.md` 中 115 张状态为 `Unrecorded` 的内联 WebP 图片**严禁复制进本仓库充当正式资产或临时占位图**，仅限在设计阶段作为角色神态与配色情绪参考。
3. **精华思想与方法论 100% 提纯升级**：选择性继承经实践检验的世界观内核、经典人物名号、雅正修真术语及硬核工程验证方法。
