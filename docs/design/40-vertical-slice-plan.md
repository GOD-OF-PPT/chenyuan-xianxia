## 1. 切片核心定位与体验目标

本垂直切片并非简陋的“技术 Demo”，而是**直接达到 Steam 正式发售品质标尺的第一章完整可玩成品（目标净游玩时长 75–120 分钟）**。

玩家在这 1–2 小时内将完整体验本作四大招牌魅力的化学反应：
1. **《魔兽世界》手感**：大地图无缝拉怪开战、锁定自动平砍、1.5s GCD 技能循环、鼠标悬停给队友加血、`Tab+Q` 秒断敌方琥珀金读条、走位躲朱砂危招圈与 `Space`【战术凝时】从容框选微操；
2. **《梦幻西游》博弈**：【天覆阵 / 地载阵】常驻光环阵位分配、装备【晶清/破血】蓝字特技惊喜，以及山道奇遇契约初生灵宠**【青岚幼狐 / 玄甲幼龟】**体验 `Ctrl+1/2` 宠物绝技助战（不提前暴露复杂打书菜单，保持初期心流纯粹）；
3. **《凡人修仙传》底色**：身怀漏灵废体的顾长青在听雨镇散修地摊靠【断玉剑匣】微光感应捡漏、首炼 15s 文武控火成丹、用剑匣暗格提纯废丹、贴【敛息符】绕过强敌摸灵草、反杀见财起意的黑衣劫修搜刮【储物袋】；
4. **《诛仙》宿命风骨**：宋明青绿山水烟雨画卷下，与医修沈清禾温药护脉的静水流深、与青云少君裴照的少年锋芒碰撞，以及章末直面“纳灵髓强冲仙脉 vs 散灵髓化雨救镇”的第一次沉重道心叩问。

## 3. 五阶段实施里程碑与强制闸门（S0 → S4）

严格遵循“仿真与样片先行，灰盒验证手感，精修装配封包”的工业化节奏，每个阶段独立走 `codex/slice-sX-*` 分支与 PR：

```mermaid
flowchart LR
  S0["S0：闸门2仿真 + 闸门3四张1080p目标样片"] --> G{"负责人样片签字"}
  G --> S1["S1：Godot工程初始化 + 灰盒RTwP战斗核"]
  S1 --> S2["S2：青岚三连箱庭Y-Sort与角色关键帧装配"]
  S2 --> S3["S3：剑匣炼丹/地摊夺宝/立绘剧本与音效合龙"]
  S3 --> S4["S4：存档加固/CI全绿/PC+Web试玩包交付"]
```

### 里程碑 S0 · 闸门 2 数值仿真 & 闸门 3 四张 1080p 美术样片（写业务代码前必过！）
- **任务 S0-1（闸门 2）**：编写独立无头战斗数值仿真脚本 `tools/combat_sim_ch01.py`，代入 `10` 与 `11` 号文档公式跑通第一章小怪与【雾隐狼王】1,000 次模拟，验证五行破罡连携、地载阵减伤、打断收益与 120–150s 首领战时长完全达标，输出仿真报告。
- **任务 S0-2（闸门 3）**：严格按 `20-art-bible.md` 宋明青绿山水重彩风与乌木宣纸 UI 规范，产出 **4 张 1920×1080 目标样片**（听雨镇街巷、古窟狼王 RTwP 团战 HUD、破庙立绘对话、万象道匣修行页）。
- **退出闸门**：**必须经项目负责人亲自审阅 4 张样片确认“彻底无塑料感、审美立住”后，方解锁 S1 工程代码开发！**

### 里程碑 S1 · Godot 4 底座与灰盒 RTwP 战斗手感原型
- 初始化 `project/` 三层架构（`core_rules / game_state / presentation`）、JSON 配表加载器与唯一键鼠 `input_router.gd`。
- 在灰盒测试场完整跑通：WASD 走位、自动普攻、1.5s GCD、琥珀金条 `Q` 键秒断、杀意仇恨变色姓名板、鼠标悬停小队框加血、五行母子印记引爆、灵宠 `Ctrl+1/2` 指令及 `Space`【战术凝时】框选走位与技能预排。

### 里程碑 S2 · 青岚三连无缝箱庭与精修美术装配
- 完成听雨镇、风雨山道破庙、苍木古窟的灰盒拉怪动线测试，再按五步入库铁律装配经 LUT 校色的四层 Y-Sort 手绘建筑树木组件与顾长青/沈清禾/裴照/幼宠/狼王斜向关键帧动画，通过 `manifest_guard` 100% 溯源检查。

### 里程碑 S3 · 经济造物、修真奇遇与三层叙事合龙
- 实装《万象道匣》有效页签（修行兵甲、道途奇门、行囊剑匣、问道手札）、首炼 15s 文武控火与剑匣废丹提纯、地摊微光捡漏与竹林劫修储物袋事件、立绘演剧台（400ms 防误触锁 + 禁空格跳句）、破庙动态 CG 及同 BPM 双轨无缝民乐混音。

### 里程碑 S4 · 存档容错加固、性能打磨与试玩封包
- 实装版本化 JSON 原子存档（覆盖新开局、石碑传送、损坏 `.bak` 恢复）、【问道败北复盘卷轴】、无障碍双编码与试玩遥测导出；跑通全套自动化门禁，导出 Windows 可执行包与 Web 试玩包交付外部测试。

## 4. 外部真人试玩验收方案（决定是否扩量全作的生死线）

交付后由项目负责人组织 **5–8 名热爱仙侠/RPG 且未参与开发的新玩家**，在 1920×1080 PC 键鼠环境下零口头指导独立游玩，对齐以下硬性通过线：

| 验收维度 | 观测与问卷指标 | 通过门槛 |
|---|---|---|
| **V1 · 完走与节奏** | 独立从听雨镇打通雾隐狼王并完成灵髓抉择，无卡死、无迷路弃坑 | **≥ 80%** 在 75–135 分钟内通关 |
| **V2 · RTwP 斗法掌握** | 战中主动使用 `Space` 凝时或快捷键完成至少 2 次读条打断、2 次五行相生连携及悬停治疗/灵宠护主 | **≥ 80%** 熟练运用核心机制取胜 |
| **V3 · 修真探索惊喜** | 自主发现地摊剑匣捡漏、使用剑匣提纯丹药或搜刮劫修储物袋，并理解无叹号《问道手札》线索 | **≥ 75%** 触发并给出高正向评价 |
| **V4 · 叙事与人设记忆** | 通关后能清晰说出顾长青求仙执念起因、剑匣藏拙危机感及自己在章末为何选纳髓或散髓 | **≥ 80%** 准确复述并产生共情 |
| **V5 · 去塑料感审美分** | 对画面工笔山水融合度、角色动作扎实度、乌木宣纸 UI 与民乐质感的 5 分制盲评 | 平均分 **≥ 4.2 / 5.0**，且 **0 例**集中吐槽“页游拼贴塑料感” |

> [!IMPORTANT]
> **铁律闭环**：若 V1–V5 任一指标未达标，严禁强行启动第二章（青云境）开发！必须定位根因回到对应子系统文档与切片定向打磨并找 3 名新玩家复测，直至垂直切片真正成为一块无懈可击的精品招牌。
