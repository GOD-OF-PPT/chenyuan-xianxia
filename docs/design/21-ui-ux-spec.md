## 1. 设计目标

1. **人体工学级魔兽战斗 HUD × 古典器物美学**：将资深《魔兽世界》团本玩家最顺手的**中下部视觉三角区（底部技能栏 + 中下偏左悬停施法小队框 + 顶部/头顶清晰读条与杀意变色姓名板）**，封装进乌木、旧宣纸与错金玉牌的古典界面中。
2. **终结弹窗地狱、蚂蚁小字与键位串扰**：全游戏功能菜单收束为唯一一卷《万象道匣》（5 页签、最多 2 层深度）；建立全工程**唯一通知中枢**与**唯一 PC 键鼠映射表（不做手柄适配）**；锁死 1080p 下 `≥ 16px` 字号硬底线。

---

## 2. 玩家体验（三尺度交互实感）

- **30 秒（战斗紧急反应）**：眼睛无需离开屏幕中央角色脚下的朱砂危招圈，余光扫见中下偏左 2 号位主坦血条变黄，鼠标直接移到主坦小队框上按技能键触发**悬停指向治疗（Mouseover Cast）**；同时看见怪物头顶亮起琥珀金读条，秒按 `Tab` + `Q` 打断，一气呵成。
- **5 分钟（整理行囊与对比换装）**：按 `B` 展开古雅宣纸《万象道匣》，鼠标移到新掉落的玄品灵佩上，右侧自动并排弹出当前穿戴灵佩的绿字增减对比与【晶清玉露】蓝字特技详解；右键秒换装，`Esc` 一键收匣。
- **1 小时（无打扰沉浸探索）**：脱战跑过青岚竹林 5 秒后，底部技能栏与小队框平滑降至 `25%` 呼吸半透（或收起次要边栏），没有一个商城红点或日常感叹号污染山水画卷。

## 3. 核心界面布局与交互规则

### 3.1 1920×1080 战斗与探索 HUD 栅格规范

```
+-----------------------------------------------------------------------+
|                                  [ 首领气血 + 五行护罡条 + 24px大读条 ] |  <-- 顶部居中（仅首领战显示）
|                                                                (小地图)|  <-- 右上淡墨圆盘（M展开）
|                                                                       |
|                     [ 核心 35° 斜俯视无缝游戏画卷 ]                    |
|                        (怪物头顶精简姓名板+杀意色+母印)                 |
|                                                                       |
|  +--------------+                                                     |
|  | F1 顾长青 阵眼|         [ 战术凝时水墨印 ] (仅Space暂停时浮现)       |
|  | F2 公输岳 镇岳|                                                     |
|  | F3 沈清禾 药灵|      [Ctrl+1][Ctrl+2] 灵宠迷你条        (通知轻签区) |
|  | F4 裴照   破锐|   +-----------------------------------+             |
|  +--------------+   |[1][2][3][4] | [Q][E][R][G] | [5][6]|[Z阵/宠]     |  <-- 底部居中乌木快捷栏
+-----------------------------------------------------------------------+
```

1. **中下偏左小队框体（Party Frames）与悬停施法**：
   - 显示 1~4 号阵位角色的气血、真元、当前护盾及最多 3 个关键状态大图标（毒瘴/破甲高亮闪烁提示驱散）。
   - **原生支持魔兽式 Mouseover（鼠标悬停施法）**：治疗或援护技能无需繁琐切换当前敌方锁定目标，鼠标指针悬停在哪名队友框体（或场景小人）上按键即对该队友生效，若未悬停友方则默认对自身或气血最低队友智能施放！
2. **智能敌方头顶姓名板（Nameplates）**：
   - **杀意（仇恨）颜色直觉编码**：主坦稳固拉住仇恨时血条边框呈**沉稳青玉色**；仇恨即将失控（90%–109%）呈**琥珀橙预警**；OT 转向当前脆皮角色时呈**朱砂红高亮跳动**。
   - 右侧醒目挂载当前附着的 **6 秒【五行母印】古篆大徽章**，方便一眼接力打出五行相生连携。
3. **脱战自动呼吸隐退**：脱离战斗满 5 秒且气血高于 90% 时，小队框体与底部快捷栏自动淡化至低存在感半透态，进入城镇或立绘对话时完全收起。

### 3.2 唯一功能菜单《万象道匣》（5 页签 · 最大深度 2 层）

废除原型散乱的几十个弹窗，所有脱战管理功能统一整合进一卷横向顶栏切换的《万象道匣》（未随章节解锁的系统页签彻底隐藏，绝不画带锁灰格子）：

| 页签序号 | 页签名称 | 唤起热键 | 包含内容（严格左右分栏，不超 2 层） |
|---|---|---|---|
| **Tab 1** | **【修行 · 兵甲】** | **`C`** | 角色切换列 + 五维自由潜能加点 + 5 槽装备穿戴 + 真实递减后属性详表 + 破境静室入口 |
| **Tab 2** | **【道途 · 奇门】** | **`N`** | 双分支道途专精天赋树（一键切流派）+ 奇门五阵图谱选择与 1~4 号阵位拖拽编排 |
| **Tab 3** | **【行囊 · 剑匣】** | **`B`** | 分类行囊（装备/丹符/灵材/奇物，支持一键按品阶整理）+ 【断玉剑匣】混元提纯双槽与丹方器谱录 |
| **Tab 4** | **【灵兽袋】** *(第2/3章解锁)* | **`P`** | 备战 3 宠排序 + 四维资质喂养 + 【定魂玉】锁槽良心兽诀打书界面 |
| **Tab 5** | **【问道手札】** | **`J`** | 主支线线索古卷 + 五大势力声望阶位 + 同伴五阶羁绊词牌 + 因果水墨签与前尘 CG 回看 |

### 3.3 唯一通知中枢（Notification Arbiter）四级优先级仲裁

全工程代码严禁私自实例化浮窗或直接往屏幕画文字，必须统一调用 `NotificationHub.push(event)`：

- **P0 · 系统级危机警报（最高优，任何时刻立显）**：存档读写失败警告（保留原档提示）、致命网络/文件异常。
- **P1 · 战斗核心反馈（仅战斗态）**：首领破罡提示、五行相生连携字样（如【木生火·燎原】）、暴击归并跳字（同一 AoE 技能多段碎数字自动合并为单次清爽总伤，拒绝数字瀑布糊屏！）。
- **P2 · 叙事演剧独占态（Tier 2/3 对话开启时）**：立即清空 P1 残留飘字，并**挂起冻结一切 P3 通知队列**。
- **P3 · 探索与收获轻签（最低优，战斗与对话中一律静默排队）**：拾取灵材灵石、手札线索更新、声望提升、【飞剑传书】送达——统一在脱战或对话结束 1.0 秒后，于屏幕右侧以最多同时 **2 条**宣纸轻签优雅滑入淡出，**绝不强制中断玩家操作弹确认框**。

### 3.4 唯一 PC 键鼠全局输入映射表（无手柄包袱，零冲突）

支持玩家在设置中自定义改键（检测冲突并标红提示），出厂默认锁死以下黄金无冲突映射：

| 语境 | 按键 | 唯一绑定行为 | 互斥防串扰铁律 |
|---|---|---|---|
| **移动与镜头** | `W / A / S / D` | 8 方向移动（对话/菜单打开时锁死移动） | 读条中按移动立即断条走位 |
| **目标与微操** | `鼠标左键` / `右键` | 左键点选目标或框选小队 / 右键对敌开自动平砍、对地走位、对友交互 | 左键永不绑定挥剑普攻 |
| **战斗核心** | `1~4`, `Q`, `E`, `R`, `G`, `5~6` | 4 核心技、打断位移、职责技、法宝大招、双人合击、双瞬发丹药 | 对话与菜单态下全部屏蔽 |
| **战术调度** | `Space`（空格） | **战场【战术凝时】暂停 / 恢复** | **在任何立绘对话与确认弹窗中，`Space` 100% 禁用按钮触发！** |
| **阵宠与切人** | `Tab`, `F1~F4`, `Z`, `Ctrl+1/2` | 智能切读条敌、切主控队员、变阵/换宠小抽屉、灵宠双绝技 | — |
| **探索交互** | `F`, `V`, `X`, `M`, `Alt` | 场景采集/交谈/破禁、御剑起落、神识破妄、大地图、按住高亮地面物名 | — |
| **叙事与系统** | `Enter`, `Esc`, `C/N/B/P/J` | **`Enter`：唯一键盘推进对话键**；`Esc`：关闭顶层面板并焦点归位 / 唤起系统菜单 | 弹窗弹出设 400ms 冷却防误触 |

## 4. 1080p 字阶规范、败北复盘与无障碍继承

### 4.1 1920×1080 字体与字号硬底线（使用合规开源/系统宋体与楷体）
- **严禁全工程任何可见 UI 出现 `< 16px` 的文字！**
- **三级标准字阶**：
  - 辅助角标（快捷键字母、堆叠数量）：**`16px`**（高对比描边）；
  - 正文基准（装备词条、技能说明、手札笔记）：**`18px–20px`**（行高 1.5 倍，旧宣纸深墨色对比度 $\ge 7.0:1$）；
  - 叙事对白与首领读条/区域名号：**`22px–28px`**。

### 4.2 升级继承原型精华：【问道败北复盘卷轴】与无障碍（a11y）
1. **【问道败北复盘卷轴】**：小队全灭时绝不自动跳场景，弹出清晰古卷复盘：
   - **致死溯源**：精确记录最后 5 秒致命伤害链（例：`雾隐狼王【腐木咆哮（可打断金条）】造成 195 木系伤害，未触发打断或【罗汉金钟】`）；
   - **破局锦囊**：针对性提示 1 条机制对策（如：“裴照【惊鸿剑指（Q）】可打断琥珀金条吟唱，或战前切换【地载阵】减伤”）；
   - **主动选择恢复**：由玩家主动点击【退回门前引灵石碑重整（战利品与地图进度 100% 保全）】或【读取存档】。
2. **无障碍与舒适度设置（持久化于独立设置文件）**：
   - 屏幕震动与受击顿帧强度滑块（`0%–100%`，默认克制 `40%`）；
   - **减弱动态效果（Reduced Motion）**：关闭水墨转场闪烁与镜头晃动；
   - **五行色觉辅助双编码**：所有五行护罡、母印与地面预警同时具备**独特古篆字形/几何边框 + 颜色**，色弱玩家零障碍辨识。

- **全作与切片共用**：由于 UI 框架在垂直切片即需达到正式版品质，第一章切片即完成整套乌木宣纸九宫格底板、快捷栏玉牌框、4 人小队框体、鼠标指针（常态玉簪/敌方剑锋/交互灵手）及 5 页签《万象道匣》母版。

## 7. 原型反模式与防呆纪律

| 原型 `chenyaun-v2` 界面灾难 | 本规范确立的根除铁律 |
|---|---|
| 几十处 9–11px 硬编码小字绕过 CSS 变量，1440×900 下眯眼都看不清 | Godot Theme 全局锁死最小字号 Token `fs_min = 16px`，CI 脚本扫描 `.tscn` 拦截任何小于 16 的字号覆盖 |
| 扫荡、兵解、买东西偶发嵌套按钮或误触扣费 | 涉及高价值灵石竞拍、点化覆盖、无丹强行逆脉破境，一律要求明确的**二次确认框或 0.8s 长按确认条** |

---

## 8. 验收标准

1. **自动化 UI 扫描**：全部 `.tscn` 场景字号 $\ge 16\text{px}$、对比度达标、所有模态框关闭后键盘/鼠标焦点 100% 归位无丢失。
2. **盲测可读性**：截取团战最高峰画面（5 友方 + 4 敌方 + 1 地面红圈 + 1 首领读条），未玩过的测试者在 2 秒内能指认谁在挨打、谁在读条、按哪个键打断。
